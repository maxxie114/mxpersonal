Agentic Inferential Metaphor Identification

Which metaphors help readers reason about how something works? I built a four-agent annotation pipeline to identify those expressions for ECOLE Lab’s research on text simplification.

View code on GitHub

What a metaphor lets a reader infer

Consider the phrase “a bottleneck in the approval process.” The narrow neck of a bottle helps explain how one slow step can hold up everything behind it. If a simpler rewrite removes the metaphor, can the reader still infer why the delay spreads? The pipeline identifies expressions like these for closer study.

From a candidate to an annotation

The first agent proposes possible metaphors. The second uses the lab’s annotation criteria to decide whether each expression supports an inference. The third extracts the exact words from the sentence. A fourth agent reviews the selection independently, and a final pass removes overlapping spans. The output links each retained phrase to its source sentence so a researcher can inspect the choice.

What changed across runs

On a batch of 100 sentences, an early run kept common expressions that contributed little to the reader’s reasoning. Tightening the criteria too far left just one span. The fourth run produced 110 spans, which became 90 after deduplication. The repository includes the outputs from each run so readers can compare individual annotation decisions.
