Projects

Selected engineering work.

I build language tools and AI agents. During my M.A. in Linguistics at San Francisco State University, I focused on computational linguistics, studying how well language models reason about language and what happens to meaning when they simplify a text. I use Python, Java and SQL to build data pipelines, and Linux and Docker to run the systems that depend on them.

I’m a nine-time hackathon winner. I enjoy working with a team to turn an idea into a prototype we can test in a weekend. Recent projects include multi-agent workflows built with LangChain and Google ADK, and a crypto risk analysis tool that uses TRM APIs to help explain what’s happening on-chain.
